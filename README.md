# 🌤️ Weather App

A sleek, responsive, and dynamic weather application that provides real-time meteorological data, forecasts, and condition insights for locations worldwide.

---

## ✨ Features

- **Current Weather Conditions:** View live temperature, humidity, wind speed, pressure, and atmospheric details.
- **Search Functionality:** Instantly look up weather information for any city or region globally.
- **Forecasts:** Access extended hourly or multi-day forecasts to plan ahead.
- **Dynamic UI:** Clean and intuitive user interface with responsive elements tailored for weather changes.
- **Error Handling:** Gracefully manages invalid city inputs or network connectivity issues.

---

## 🛠️ Tech Stack


- **Frontend:** Frontend Tech-Flutter 
- **State Management:** State Management Tool-Provider
